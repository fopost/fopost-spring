# fopost-spring-boot-starter

Official Spring Boot starter for the [FoPost](https://fopost.com) API. Schedule and publish to +30
social platforms from your Spring application.

A thin wrapper around [`com.fopost:fopost-java`](https://github.com/fopost/fopost-java): it
auto-configures the client, binds `fopost.*` properties, adds an actuator health indicator, and
turns incoming FoPost webhooks into Spring application events.
